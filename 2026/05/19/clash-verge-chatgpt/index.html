Clash Verge 配置与 ChatGPT 注册使用教程

Created2026-05-19|Updated2026-05-19|教程
|Post Views:

本文记录一次在 Windows 电脑上配置 Clash Verge，并访问 ChatGPT 官网完成注册的基础流程。

说明：请在符合当地法律法规、学校或单位网络规定，以及相关服务条款的前提下使用。订阅链接通常包含私人 token，不建议直接公开发布到博客或仓库中。

一、准备工作

开始前需要准备：

  1. 一台 Windows 电脑；
  2. Clash Verge 安装包，例如 Clash.Verge_2.2.3_x64-setup.exe；
  3. 可用的订阅链接；
  4. 一个用于注册 ChatGPT 的邮箱，例如 QQ 邮箱。

二、安装 Clash Verge

双击安装包，按提示完成安装。第一次打开软件后，如果左上角提示有更新，可以先点击更新，更新完成后再继续配置。

打开后可以看到 Clash Verge 的主界面：

三、导入订阅

进入左侧的「订阅」页面，在订阅链接输入框中粘贴你的订阅地址。

不要把真实订阅链接公开写到博客中。公开教程建议写成下面这种占位形式：

粘贴后点击「导入」。导入成功后，订阅列表中会出现对应的订阅卡片，并显示流量和到期时间等信息。

四、选择节点并开启系统代理

回到「首页」，在「当前节点」区域选择一个可用节点。例如这里选择的是新加坡节点。

然后在「网络设置」中打开「系统代理」。开启后，系统中的浏览器和常用软件会通过该代理访问网络。

如果节点连接正常，左下角一般会出现上传、下载速度变化。此时基础网络配置就完成了。

五、测试网络是否可用

打开浏览器，访问一个需要测试的网页。如果网页可以正常打开，说明代理基本配置成功。

如果无法打开，可以依次检查：

  1. Clash Verge 是否正在运行；
  2. 「系统代理」是否已经开启；
  3. 是否选择了可用节点；
  4. 订阅是否已经成功导入；
  5. 订阅是否过期，或者流量是否用完；
  6. 浏览器是否开启了其他代理插件，导致代理冲突。

六、访问并注册 ChatGPT

网络测试通过后，打开 ChatGPT 官网：

进入官网后，选择注册账号。可以使用自己的邮箱注册，例如 QQ 邮箱。按照页面提示完成邮箱验证和账号创建即可。

注册完成后，再次访问 ChatGPT 官网并登录，就可以开始使用。

七、常见问题

1. 订阅导入后没有节点怎么办？

先点击订阅旁边的刷新按钮。如果仍然没有节点，可能是订阅链接填错、订阅过期，或者网络本身还没有连通。

2. 已经开启系统代理，但网页还是打不开怎么办？

可以先切换其他节点，再刷新网页。如果仍然失败，重启 Clash Verge 和浏览器。还不行的话，检查是否有其他代理软件或浏览器插件正在接管网络。

3. ChatGPT 页面能打开，但登录或注册失败怎么办？

先确认邮箱是否可以正常接收验证码。也可以换一个浏览器，或者清理浏览器缓存后重新尝试。

4. 配置完成后以后怎么使用？

以后一般只需要打开 Clash Verge，确认系统代理已经开启，并选择一个可用节点，然后再访问 ChatGPT 官网即可。
